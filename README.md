# Kalkulator Web - CodeIgniter

Proyek pembelajaran membuat aplikasi kalkulator sederhana berbasis web menggunakan framework **CodeIgniter**. Repositori ini dibuat untuk memahami konsep dasar arsitektur MVC (Model-View-Controller) dan sistem *routing* pada CI.

## Fitur
* Operasi matematika dasar:
  * Penjumlahan (+)
  * Pengurangan (-)
  * Perkalian (x)
  * Pembagian (/)
* Antarmuka web yang sederhana dan interaktif.

## Teknologi yang Digunakan
* **Bahasa:** PHP
* **Framework:** CodeIgniter
* **Tampilan:** HTML & CSS
* **Server Lokal:** XAMPP

## Cara Menjalankan Proyek (di Komputer Lokal)
1. Pastikan Anda sudah menginstal **XAMPP** dan menyalakan modul **Apache**.
2. *Clone* atau unduh repositori ini dan letakkan di dalam folder `C:\xampp\htdocs\`.
3. Buka *browser* (Chrome/Edge/Firefox) dan akses URL berikut:
   `http://localhost/Belajar_kalkulator/public/`
